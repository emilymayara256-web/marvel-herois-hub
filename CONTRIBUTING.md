# Como contribuir

1. Abra uma **Issue** descrevendo a mudança (use os templates).
2. Crie uma branch a partir da `main`: `feature/nome-curto` ou `fix/nome-curto`.
3. Faça commits no padrão **Conventional Commits**, por exemplo `feat(quiz): adiciona nível difícil`.
4. Rode `npm test` antes de abrir o Pull Request.
5. No Pull Request, escreva `Closes #N` na descrição para fechar a Issue ao fazer merge.
6. Aguarde o check `test` ficar verde. A `main` é protegida e só recebe merge por Pull Request.
